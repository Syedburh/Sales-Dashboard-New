# 📊 Sales Dashboard | Power BI

## 🔍 Project Overview
This Power BI dashboard provides an end-to-end analysis of sales performance, returns, orders, and regional trends to support data-driven business decisions.

## 📌 Key Metrics
- **Total Sales:** 125K
- **Total Orders:** 25K
- **Total Returns:** 2K

## 📈 Dashboard Insights
- Sales trend analysis by month and year
- Product-level sales performance
- Category-wise orders, returns, and revenue
- Net sales distribution across regions and continents
- Return analysis by product category

## 🛠 Tools & Technologies
- Power BI
- DAX
- Excel / CSV
- Data Modeling & Visualization
